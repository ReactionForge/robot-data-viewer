# Robot Data Viewer v2 — 原生画幅 · 七路清晰观看

独立、纯前端的离线会话回放页。把设备导出的会话 `.tar` 直接导入，即可同步播放七路（或自定义任意路数）相机画面。v2 重点解决“总览 3840×1080 被压成 16:9 小条看不清”的问题。

## 特点

- **完全离线、零依赖**：`index.html` + `styles.css` + `app.js` + `tar.js`，双击 `index.html`（`file://`）即可使用，无构建、无 CDN。
- **原生画幅**：卡片宽高比在 `loadedmetadata` 后由 `videoWidth / videoHeight` 写入 `--ar`，不再统一 16:9。
- **三套布局 + 单屏**：清晰（默认，总览整行跨满 / 腕各半行 / 触觉四列）、紧凑（小卡片头、8px 间距）、单屏（总览整行 + 其余六路压成一行，自动收起标题与底部区域，七路一屏看全）、自适应（按实际可用宽度自动取 4 / 2 / 1 列，总览与双眼始终占满整行，不会把总览缩成小卡片）。
- **总览合并 / 双眼**：合并时按真实 32:9 显示整行；双眼时拆成两张 16:9 卡片，同一 blob URL 绑定两个 video（`width:200%; height:100%; object-fit:fill`，左眼 `left:0`、右眼 `left:-100%`），并加入同步引擎。源画幅非约 32:9 时自动禁用拆分。
- **聚焦层**：点击任意画面或 `⤢` 打开大画面（`object-fit:contain`），支持 适应 / 100% / 200% / 400% 缩放与拖动平移，`Esc` 关闭、`Space` 播放/暂停。
- **单帧步进**：底部 `◀|` / `|▶` 按钮，步长 `1/fps`（fps 取 metadata 或 30 兜底），并显示 `frame N / M`。
- **同步播放**：以第一路为时钟，所有通道 `play / pause / seek / 变速` 同步；根据 `timestamps.csv` 显示每路相对对齐偏差（Δ ms）。布局/通道切换、双眼切换时保持当前时间与播放状态。
- **七路 / 自定义路数**：`全部相机 / 主相机 / 触觉相机` 快速筛选；`自定义` 面板可勾选通道、设定显示路数与网格列数。
- **响应式**：≥1400px 四列基础网格；900–1400px 触觉 2×2；<900px 单列。侧栏折叠后 mosaic 自动铺满。
- **兼容导出格式**：识别 `metadata.json` 与 `observation.image.<role>/video.mp4`，并自动映射为中英文相机名；H.265/HEVC 不支持时卡片内显示错误层与提示。

## 使用

1. 从设备导出会话数据包 `.tar`。
2. 打开 `index.html`（推荐 Microsoft Edge；若浏览器不支持 H.265/HEVC 解码，页面会给出提示）。
3. 点击 `Open TAR` / `导入 TAR`，或把 `.tar` 拖到页面任意位置；也可点击 `Open folder` 载入已解压目录。
4. 导入后自动播放。用工具栏切换 `清晰 / 紧凑 / 单屏 / 自适应`；想一屏同时看全七路就选 `单屏`。用底部控制条播放/暂停、拖动进度、倍速、单帧步进；用 `⤢` 或点击画面聚焦单路。

## 快捷键

| 键 | 作用 |
|---|---|
| `Space` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `,` / `.` | 单帧后退 / 前进 |
| `F` | 全屏切换 |
| `1`–`7` | 聚焦对应通道 |
| `Esc` | 关闭聚焦层（或退出全屏） |

## 说明

- 所有处理都在浏览器本地完成，文件不会上传到任何服务器。
- 视频为 H.265/HEVC MP4（与设备导出一致），需要浏览器具备 HEVC 解码能力。Windows 上推荐 Microsoft Edge；Chrome 若无法解码，请安装/启用 HEVC 视频扩展。
- 本工具仅用于离线回放，不参与采集、同步、导出流程；不影响 179 板端采集（不引用、不修改 `app.py`、`scripts/recorder_next/*`，不启动服务、不占用端口）。

## 文件

- `index.html` — 页面结构（工具栏、mosaic、聚焦层、帧步进控件）
- `styles.css` — 深色主题、原生画幅网格、三套布局、双眼裁剪、聚焦层、响应式
- `app.js` — 导入、通道识别、布局引擎、双眼拆分、聚焦/缩放、帧步进、快捷键、持久化
- `tar.js` — 无依赖的浏览器端 TAR 解析器（支持 ustar / GNU 长名 / PAX），本次未改动
